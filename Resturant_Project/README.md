# 🍽️ CraveHub - EnjoyYourMeal

A premium, modern restaurant website built with Django. CraveHub offers a sleek Dark Glassmorphism UI, a fully functional shopping cart, an online table booking system, and dynamic customer feedback.

## 🚀 Live Demo
**[https://enjoyyourmeal.onrender.com](https://enjoyyourmeal.onrender.com)**

---

## ✨ Features
- **💎 Premium Design:** Dark Glassmorphism UI/UX with smooth animations and responsive layouts.
- **🛒 Smart Shopping Cart:** Persistent, database-driven cart for seamless ordering.
- **📅 Table Booking:** Easy online reservation system with email confirmation capability.
- **💬 Feedback System:** Dynamic customer reviews with star ratings.
- **📦 Menu Management:** Categories and food items managed easily via a powerful Admin Panel.
- **🌍 Localization:** Fully localized in English with Indian Rupee (₹) currency.

---

## 🛠️ Tech Stack
- **Backend:** Django 5.0.6 (Python)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript, jQuery
- **Database:** SQLite (Development) / PostgreSQL (Production)
- **Deployment:** Render / GitHub

## 🛠️ Local Setup
1. **Clone the repo:**
   ```bash
   git clone https://github.com/amanjain-31/EnjoyYourMeal.git
   cd EnjoyYourMeal
   ```
2. **Setup Virtual Environment:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
3. **Install Dependencies:**
   ```bash
   pip install -r Resturant_Project/requirements.txt
   ```
4. **Environment Variables:**
   Create a `.env` file in the `Resturant_Project` folder:
   ```
   SECRET_KEY=your_secret_key
   GOOGLE_MAPS_API_KEY=your_maps_key
   ```
5. **Run the Server:**
   ```bash
   python Resturant_Project/manage.py runserver
   ```
