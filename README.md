# EnjoyYourMeal - Restaurant Web Application

A modern Django-based restaurant management and ordering web application with user authentication, menu browsing, table booking, shopping cart functionality, and customer feedback system.

## Features

### Core Functionality
- **User Authentication**: Secure login and signup with Django's built-in auth system
- **Menu Management**: Browse restaurant menu items by category with images and descriptions
- **Shopping Cart**: Add items to cart, manage quantities, and track items
- **Table Booking**: Reserve tables with customer details and preferred dates
- **Feedback System**: Submit and view customer ratings and reviews with image uploads
- **Admin Panel**: Manage items, categories, bookings, and feedback through Django admin

### Database Models
- **ItemList**: Menu categories
- **Items**: Individual menu items with price, description, category, and images
- **Cart**: User shopping cart with item quantities
- **BookTable**: Table reservation bookings
- **Feedback**: Customer reviews with ratings and images
- **AboutUs**: Restaurant information and description

## Tech Stack

- **Framework**: Django 5.0.6
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, JavaScript (Bootstrap, jQuery)
- **Image Processing**: Pillow
- **Environment Management**: python-dotenv
- **Email**: Gmail SMTP integration
